# Dairy Management System

The Dairy Management System is a comprehensive web-based application designed to streamline dairy operations. It includes features for managing employees, inventory, and logistics, ensuring efficiency and data integrity. The system is built with a secure backend and a user-friendly frontend.

---

## **Features**
1. **Employee Management**
   - Add, view, update, and delete employee records.
   - View consolidated data of employees and their shift assignments.

2. **Inventory Management**
   - Monitor raw milk intake and processed product inventory.
   - Track stock movements and maintain records of transactions.

3. **Logistics and Warehouse**
   - Manage logistics equipment and warehouse storage effectively.

4. **Admin Tools**
   - Exclusive SQL Queries page for advanced database operations.

---

## **Technologies Used**
- **Frontend**: HTML5, CSS3
- **Backend**: Node.js, Express.js
- **Database**: MySQL
- **Database Interaction**: MySQL2 library
